# L-Mechrevo

L-Mechrevo 是一个面向机械革命（Mechrevo / Uniwill 代工）机型的开源控制台，运行在 Windows 托盘，通过机器上已有的 GCU 硬件服务读取传感器状态并下发控制命令。它把性能模式、自定义功耗、键盘灯效、屏幕与电池等常用控制收进一个轻量窗口，不支持的机型入口会自动隐藏。

## 功能特性

### 性能模式

- **静音 / 平衡 / 狂暴**：三档基础性能模式，一键切换（`Settings.cs` 性能面板分段按钮）。
- **静音狂暴**：狂暴模式的静音子模式，风扇策略更安静；只在机型能力确认支持时显示，不支持的机器上自动隐藏（`Settings.cs:2017`，能力判定见 `Settings.cs:2815`）。
- **自定义**：打开自定义性能模式窗口（`CustomModeForm.cs`）。

### 自定义性能模式（4 个槽位）

- **自定义 1～4**：四个独立槽位，各自保存一套参数，切换时自动应用（`CustomModeForm.cs:132`）。
- **CPU 功耗墙 PL1 / PL2 / PL4**：按机型回读范围提供滑条，PL4 瞬时功耗墙不是所有机型都上报，范围无效时该行自动隐藏（`CustomModeForm.cs:392-396`）。
- **睿频模式**：禁用睿频 / 启用睿频 / 激进睿频 / 效率睿频，按自定义档独立保存（`WinPowerPlan.cs:45-48`）。
- **Windows 电源计划**：按自定义档独立保存与应用（`WinPowerPlan.cs`）。
- **GPU 超频**：核心 / 显存频率偏移与电压偏移，走 NVIDIA 驱动直连或 GCU 的 LCHWOC 通道，任一可用时显示（`CustomModeForm.cs:430`）。
- **风扇曲线**：16 个固定温度档的占空比曲线点，鼠标拖动实时保存；支持「风扇独立控制」（关 = 双风扇跟随 GPU 曲线，开 = CPU/GPU 各自独立）（`FanCurveForm.cs:12-13`）。
- **恢复当前档默认**：一键把当前自定义档的参数恢复默认（`CustomModeForm.cs:459`）。

### 灯光

- **键盘灯效**：10 种软件渲染效果（流畅彩虹、静态、呼吸、闪烁、按键反应、彩虹轮、闪电、火焰、雨滴、矩阵），各效果带专属参数（方向 / 速度 / 颜色等）（`RgbForm.cs:14-20`）。
- **灯条灯效**：单色、呼吸、波浪、冲击、流星，带亮度档 / 速度 / 单色颜色（`LightForm.cs:13-16`）。仅灯带硬件存在时显示。
- **Logo 灯效**：单色、呼吸、混合（`LightForm.cs:17-20`）。仅 Logo 灯硬件存在时显示。
- **离电自动关闭全部灯效**：拔掉电源后自动熄灭所有灯（`Settings.V2.cs:583`）。
- **睡眠时间**：关闭 / 10 秒（软件）/ 10 分钟～2 小时，空闲后自动熄灯（`Settings.V2.cs:659-664`）。

### 液冷系统（外接水冷机）

- **连接状态**：自动连接 GCU 通道，失败时可尝试蓝牙直连（`Settings.cs:986` 起）。
- **泵速档位**：自动 / 45% / 60% / 最大（90%）（`Settings.cs:1270` 起）。
- **风扇档位**：自动与多档手动（`Settings.cs:1336` 起）。
- **液冷灯光**：水冷头 / 风扇灯效菜单，依赖 Mk2 风扇灯能力（`UI/LiquidCoolingLightMenu.cs`）。仅连接水冷机时显示。

### 屏幕

- **刷新率**：按机型支持的频率列表生成分段按钮，一键切换（`Settings.V2.cs:161`）。
- **自动刷新率**：按需自动切换刷新率（`Settings.cs:812`）。
- **亮度**：Windows 标准亮度滑条（`Settings.cs:857`）。
- **屏幕校色**：默认 / sRGB 两档色域切换（`Settings.cs:918-919`）。
- **响应加速**：Overdrive，在设置弹窗中，机型支持时显示（`Settings.cs:107`）。
- **息屏（不睡眠）**：一次性压暗屏幕并顶住待机，动鼠标或键盘即恢复（`Settings.cs:641`）。

### 显卡模式

- **节能 / 标准 / 独显直连 / 核显 / 自动**：切换显卡输出模式，部分模式切换需要重启生效（`Settings.cs:4044-4060`）。

### 电池

- **电池保护三档**：性能 / 平衡 / 健康（`Settings.cs:2145`）。
- **限充**：连续滑条设置充电上限百分比（`Settings.cs:2151`）。
- **充满**：临时把上限恢复到 100%（`Settings.cs:3184`）。

### 更多开关

- **输入设备**：触摸板、触摸板切换键、WiFi、蓝牙、摄像头、小键盘锁。
- **键盘与热键**：Win键锁、Fn键锁、Copilot键锁、OSD提示。
- **电源与系统**：USB充电、高性能电源、风扇增强、来电自启、CPU高级性能、游戏白名单、任务栏自动隐藏、透明效果、深色主题、深度睡眠、息屏（不睡眠）、开机自启动。

以上开关按机型能力显示：服务端没有上报对应字段的项会整项隐藏，整组都没有可见项时连组标题一起收起（`Settings.cs:46-51`、`Settings.cs:482-506`）。

### 其他

- **遥测行**：CPU / GPU 温度、功耗、风扇转速、占空比实时显示（`Settings.V2.cs:15`）。
- **悬浮窗**：桌面硬件悬浮窗，四种形态可点击切换，可直接拖动（`Overlay/HardwareOverlay.cs`）。
- **日间 / 夜间主题**（`Settings.cs:234`）。
- **官方控制台**：检测官方控制台是否在运行，可一键「隔离官方界面与托盘」，只保留 GCU 后台服务（`FirstRunGuideForm.cs:89-91`）。
- **程序内更新**：静默检测新版本，有新版时提示，下载后自动校验 SHA-256 并拉起更新器（`Updates/UpdateForm.cs`）。
- **开机自启动**：用户级计划任务实现，不依赖管理员权限（`Settings.cs:704`）。

## 下载

在 [Releases](https://github.com/LiangyuLu-lly/L-Mechrevo/releases) 页面提供两种包：

- `L-Mechrevo-<版本>-setup.exe`：全新安装包，自带 .NET 运行时与 GCU 服务载荷，第一次使用下载这个。
- `L-Mechrevo-<版本>-unsigned.zip`：已有版本的自动更新包。程序内检测到新版会自动提示；也可以手动下载 zip，解压后自行替换程序文件。

## 系统要求

- Windows 10 / 11 64 位。
- 机械革命（Mechrevo / Uniwill 代工）机型。
- GCU 硬件服务（安装器会自动按显卡代际部署对应载荷）。
- 部分功能因机型硬件而异，不支持的入口会自动隐藏。

## 安装与首次使用

1. 从 Releases 下载 `L-Mechrevo-<版本>-setup.exe`。
2. 运行安装向导，按提示完成安装。
3. 安装器会自动检测显卡代际（40 系 / 50 系），部署对应的 GCU 服务载荷与驱动。
4. 安装完成后首次启动程序。
5. 如安装器提示需要重启，请重启一次再使用。
6. 程序常驻系统托盘，双击托盘图标打开主界面。
7. 如需开机自启，在主界面「更多开关 → 电源与系统」里打开「开机自启动」。

## 使用说明

### 切换性能模式

主界面性能面板有五个分段按钮：静音、平衡、静音狂暴、狂暴、自定义。点按即切换，当前档位高亮。静音狂暴只在机型支持时出现。托盘右键菜单里也能切换，菜单项为「静音 (办公)」「平衡 (游戏)」「静音狂暴」「狂暴 (增强)」。

### 自定义模式槽位

点「自定义」打开自定义性能模式窗口，左侧选择自定义 1～4 槽位。每个槽位可设置：

- CPU 功耗墙 PL1 / PL2（部分机型还有 PL4 瞬时功耗墙）滑条。
- 睿频模式下拉（禁用 / 启用 / 激进 / 效率）。
- Windows 电源计划。
- GPU 超频开关与频率 / 电压偏移数值。
- 「风扇曲线」按钮打开曲线编辑器，拖动 16 个温度档的曲线点调整占空比，可开「风扇独立控制」。

改完点保存，参数写入当前选中的槽位；点「恢复当前档默认」可还原。

### 键盘灯效与灯带 Logo

主界面「灯光」组有三行：键盘、灯条、Logo。每行有电源开关、效果下拉和「编辑」按钮。下拉直接选效果，「编辑」打开对应窗口调参数（键盘灯效的方向 / 速度 / 颜色，灯条与 Logo 的亮度档 / 速度 / 单色颜色）。灯光组顶部还有「离电自动关闭全部灯效」开关和「睡眠时间」下拉。灯条与 Logo 两行只在机器带对应硬件时显示。

### 熄灯休眠时间

「灯光」组顶部的睡眠时间下拉可选：关闭、10 秒（软件）、10 分钟、15 分钟、20 分钟、30 分钟、45 分钟、1 小时、2 小时。到时后所有灯自动熄灭。

### 液冷档位

「液冷系统」组显示连接状态，未连接时点击可发起连接。连接后可调「泵速」（自动 / 45% / 60% / 最大）与「风扇」档位，「灯光」按钮打开液冷灯效菜单。

### 屏幕刷新率与色域

「屏幕」行按机型支持的频率显示分段按钮，点按切换；行头右侧有「自动刷新率」开关和「屏幕校色」下拉（默认 / sRGB）。亮度滑条在同一行。

### GPU 模式

显卡面板提供节能、标准、独显直连、核显、自动。切换独显直连 / 核显这类需要重启的模式时，程序会提示重启。

### 更多开关

「更多开关」卡片分三组：输入设备、键盘与热键、电源与系统。每项是一个开关，点按即下发命令，命令确认前开关会短暂禁用。深度睡眠改动需重启才生效，程序会弹窗提示。

### 程序内更新

程序启动后会静默检测新版本，有新版时更新按钮出现角标。点开更新窗口可查看更新说明，点「下载并安装」自动下载、校验并拉起更新器；网盘发布的版本点「打开下载页」手动下载。

## 常见问题

**提示 GCU 未连接怎么办？**
GCU 硬件服务尚未连接时，涉及硬件的命令会提示「GCU 硬件服务尚未连接，请稍后再试」。请确认官方控制台已安装、GCU 服务在运行，稍等片刻后重试。

**某些功能看不到？**
机型不支持的功能入口会自动隐藏，例如静音狂暴、灯带、Logo、PL4 功耗墙。这是按机型能力设计的，不是故障。

**没收到更新提示？**
更新检测需要当前版本已过期且网络可达。可以手动打开更新窗口检查，或到 Releases 页面下载。

**用了第三方远程 / 串流软件（如 UU远程）的「隐私屏」后本地屏幕变黑？**
这是远程软件隐私屏功能的正常行为，不是本程序故障。关闭远程端的隐私屏即可恢复。

**用了「息屏（不睡眠）」后屏幕黑了怎么恢复？**
动一下鼠标或键盘即可恢复亮屏。

**自定义功耗 / 超频有风险吗？**
有。功耗墙、超频、风扇曲线等操作可能影响稳定性与硬件寿命，请自行评估，风险自负。
