LMechrevo.LpcACPIEC.bin
=======================

(L-Mechrevo.csproj) and therefore redistributed as part of L-Mechrevo.

Interface exposed by the module (verbatim from upstream LpcACPIEC.p):
  ioctl_pio_read  (in: port ; out: value)  -- port allowlist: 0x62, 0x66 only
  ioctl_pio_write (in: port, value)        -- port allowlist: 0x62, 0x66 only
  Callers should acquire the "\BaseNamedObjects\Access_EC" mutant before calling.

The EC mailbox transport implemented in ../source/MechrevoLite.Hardware/EcPortIo.cs follows the
ITE IT5570 EC mailbox convention (command 0x92 read / 0x93 write over data port 0x62 with the
status/command port 0x66), as documented by the JiaoLong16Pro-Battery-threshold project and by
the vendor control centre EC path. Only protocol facts (port roles, command bytes, address
layout) were taken; no third-party code was copied.

⚠️ This module grants raw port I/O for ports 0x62/0x66 only. It is loaded lazily, only while a
   caller actually needs XRAM access, and is never used to reach ports outside that allowlist.
   WinRing0 / inpoutx64 are deliberately NOT used (their drivers are non-compliant to redistribute).
