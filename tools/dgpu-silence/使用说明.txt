========================================
 同方核显省电工具箱 —— 使用说明
========================================

【这是什么】
  一个面向同方（TongFang）模具机型的显卡工具：读取显卡/固件信息、生成报告，
  也可以（在你确认后）禁用/启用独显、热切换、调整 GPU 功耗上限。

  * 只读操作：菜单 1~6（体检、快照、对比、看状态、释放占用前的列表）
  * 会改动硬件的操作：菜单 7~11、13 —— 全部会先显示只读状态，再让你输入 YES 确认
  * 菜单 13（GPU 功耗上限）是一份参考实现：目前只在 4060 上验证过，其它机型请先只读确认
  * 菜单 13 里「离电参考值」中的 0x7C4 / 0x751 / 0x7CC 属于未确认地址，
    工具默认【只读展示、不写入】，以规避伪造电池状态影响充电/功耗策略的风险。

【怎么用】
  1. 把整个文件夹保持原样（不要只拷其中一个文件）。
  2. 双击「双击运行-同方核显省电工具箱.cmd」。
  3. 弹出"用户账户控制"窗口时，点【是】。（必须点，否则读不到硬件信息。）
  4. 在中文菜单里选一个数字，按回车。

【菜单说明】
  1) 体检并生成报告到桌面 ....... 最常用，一次搞定（只读）
  2) 【推荐】切换前拍快照 ....... 配合 3 使用，见下面"正确的切换步骤"（只读）
  3) 切换后对比 ................ 自动和上次拍的快照比较（只读）
  4) 实时抓取切换过程 .......... 会全程盯着，可能干扰控制中心，成功率低（只读）
  5) 释放独显占用 .............. 控制中心提示"显卡使用中"时用（确认后才关程序）
  6) 只看一下状态 .............. 不生成报告（只读）
  7) 静默独显：禁用设备 ........ 立即生效，不经过控制中心
  8) 还原独显：恢复被禁用的设备
  9) 热切静默：免重启切走独显 .. 仅部分机型支持（support=85）
 10) 热切还原：把切走的独显切回来
 11) 强制静默（彻底）.......... 清占用 + 软硬双层，有程序在用也能做
 12) 报告开关 ................. 切换"是否在桌面生成报告文件"
 13) GPU 功耗上限 / Dynamic Boost（写 EC，仅 4060 实测）
  ?) 使用说明         0) 退出

【最重要的一条：切换时不要挂着本工具】
  机主实测：挂着抓取工具时，"核显省电模式"经常切换失败。
  原因：控制中心切换时要反复读取 EC/显卡状态来确认成功，
        本工具也在读同一处，两边互相抢，控制中心就会误判"没切成功"，
        然后自己把设置回滚。

  *** 正确的切换步骤（指用控制中心切换显示模式时）***
     a. 本工具选 2，拍一张"切换前"快照（会自动记住）
     b. 关掉本工具窗口
     c. 打开控制中心 -> 显卡模式 -> 核显省电模式 -> 选【开启】
     d. 等它提示成功（或提示需要重启）
     e. 重新双击本工具 -> 选 3，看切换前后的对比结果

【菜单 13：GPU 功耗上限 / Dynamic Boost】
  ℹ️ 参考实现：目前只在 4060 测试机（RTX 4060 Laptop，140W 档）上验证过。
     不同机型/显卡的 EC 地址与字节含义可能不同：建议先只用"只读状态"确认，
     再自行判断是否写入（有原值记录与回滚）。

  原理（4060 实测）：
    GPU 功耗上限 = 115W + Dynamic Boost（DB）最大 TGP
      25W -> 约 140W     15W -> 约 130W
      5W  -> 约 120W     0W  -> 约 115W（等同关闭 DB）

  怎么做：
    1) 选 13，先看只读状态（不会写）
    2) 选择目标档位（1~4）或 5 = 回滚原值
    3) 会先"预演"一次（显示将写入的字节，但不写）
    4) 输入 YES 才会真正写入
    5) 写入后会自动回读校验，并用 nvidia-smi 看 enforced 功耗

  注意：
    * DB 是动态的：只有 GPU 有负载时才维持高档；负载停止后固件会把值收回。
    * 写错了怎么办：本菜单选 5 回滚；或者切一次性能模式；或者重启。
    * 需要本机已安装 ACPIDriver（同方机型的管理组件会带），否则会提示打不开设备。
    * 想恢复默认：选 4（0W/115W），或选 5 回滚到进入前的值。

【选项 5：释放独显占用】
  什么时候用：控制中心里切"核显省电模式"时，红字提示
              「显卡使用中，暂不支持切换，请稍后再试」。
  做什么：先列出是哪些程序在占用独显（只读、不动任何东西），
          你选 1（关掉主要占用的几个）后它才动手关闭；
          桌面、开始菜单、防病毒、控制中心本身等关键程序不会被关。
  然后：回到控制中心点【开启】再试一次（这次别挂着本工具）。
  如果还是不行：重启一次电脑，占用一定清空。

【注意事项】
  * 菜单 5 与 11 会强制关闭程序，**程序里没保存的内容会丢失**，请先保存工作。
  * 切换瞬间屏幕可能黑 1~5 秒，属正常现象。
  * 万一黑屏不恢复：等 30 秒；仍黑就长按电源键 10 秒强制关机，再开机。
    这不会损坏硬件，也不会丢数据（报告文件已经存在桌面上了）。
  * 如果杀毒软件/安全软件拦截 PowerShell 脚本：请选择"允许/放行"。
  * 不要在记事本里另存这几个脚本文件（会把编码改坏，中文会变乱码）。
  * 千万不要运行厂商目录里的 GetGpuUsage.ps1：
    它名字像"查看占用"，实际内容是"禁用 NVIDIA 设备"，会误伤。

【文件说明】
  双击运行-同方核显省电工具箱.cmd   <- 双击这个
  GpuPowerSavingToolbox.ps1     <- 中文界面（UTF-8 带 BOM，请勿改编码）
  Get-NvramState.ps1            <- 只读引擎（体检/快照/对比）
  Clear-DgpuOccupants.ps1       <- 占用释放引擎（默认只读，-Kill 才动手）
  Invoke-DgpuSilence.ps1        <- 禁用/启用独显设备（PnP）
  Invoke-GpuHotSwitch.ps1       <- 热切换（写固件接口，含校验与回滚）
  GpuPowerLimit.ps1             <- GPU 功耗上限 / DB（写 EC，仅 4060 实测）
【如果你遇到"打不开 ACPIDriver"】
  说明：菜单 13（GPU 功耗控制）需要同方自带的 UWACPIDriver 通道。
  * 正常装了同方控制台/管理组件的机器，设备管理器里会有一个名为
    "ACPIDriver" 的 ACPI 设备（实例 ID: ACPI\INOU0000），不需要额外操作。
  * 如果脚本提示打不开 ACPIDriver：
      1) 确认控制台/管理组件是否完整安装（不要只装绿色版）；
      2) 若被卸载过：在同方控制台的安装目录里找到 UWACPIDriver
         （UWACPIDriver.inf / .cat / .sys），管理员执行：
             pnputil /add-driver UWACPIDriver.inf /install
      3) 装好后设备管理器会出现 "ACPIDriver"，重新打开工具箱即可。
  * 没有这个驱动时，菜单 1~12 里依赖固件接口的功能也会读不到（属正常）。
【技术附录：EC 字节与功耗上限的关系（同方 4060 实测）】
  * 公式：enforced（驱动实际生效上限） = 显卡默认 TGP + DB 字节值
      - 默认 TGP：115W（由 vBIOS 决定，可用 nvidia-smi 读出）
      - DB 字节：0x746 与 0x7D5（两份，值 = 额外瓦数，0x00..0x19）
  * 实测对照：0x05 -> 120W，0x0A -> 125W，0x13 -> 134W，0x00 -> 115W
  * 读取本机范围：
      nvidia-smi --query-gpu=power.default_limit,power.min_limit,power.max_limit --format=csv
      （本机：默认 115W / 最小 5W / 最大 140W，即 DB 可调 0..25W）
  * 写入顺序（模仿官方控制台）：先写 0x746，等待约 1 秒，再写 0x7D5
  * 已确认可写地址（仅这 5 个）：
      0x743  DB 使能位
      0x745  DB 目标
      0x746  DB 最大 TGP（第一份）
      0x7D4  第二份 DB 目标
      0x7D5  第二份 DB 最大 TGP
  * 未确认地址（工具只读，不写）：
      0x7C4 / 0x751 / 0x7CC
      说明：它们在离电时会变化（0x7C4: 0x38->0x20，0x751: 0x00->0xA0，0x7CC: 0x01->0x00），
            但语义未证实；为避免伪造"电池供电"影响充电与功耗策略，工具不写这些地址。
  * 离电自动压到约 35W 属于固件自身行为，本工具不复刻。
  * 写入后驱动侧可能延迟更新：请跑 GPU 负载（FurMark/游戏）后再看 enforced。
