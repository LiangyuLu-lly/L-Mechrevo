# 字体子集化 —— 保留集说明（甲方案）

## 这个目录是干什么的

存放 **HarmonyOS Sans SC** 字体子集化所需的两份材料，供机主在本机自行生成子集字体。

**本目录不会被安装包打包**（见文末「为什么放这里」）。

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `SUBSET-KEEP.txt` | **字符集文本**，直接喂给 `pyftsubset --text-file=`。UTF-8（无 BOM），含 9728 个码位。 |
| `验证-子集缺字.py` | 验证脚本：抽取源码 UI 字符 → 与子集 ttf 的 `cmap` 求差集 → 报缺字与字重。 |
| `SUBSET-KEEP-说明.md` | 本文件。 |

> 它们出现在源码里（如 `UiAuditRunner.cs:1058` 用 `'⺀'`/`'鿿'` 做码位范围判断），
> 属于**代码里真实存在的字符**。保留它们是零成本的保险做法。

## 为什么这样保留

1. **GB2312 一二级 6763 字 = 简体常用字全集**，覆盖了全部界面文案。
2. **本轮实测复核**：扫描 `source\` 下 **374 个 `.cs`**（13,079 条字符串字面量，已剔除注释）
   + **4 个 `.resx`**，得到 UI 字符 **1118 个**（汉字 964 + 非汉字 154）。
   - **964 个汉字 100% 落在 GB2312 一二级内**（逐字校验，0 例外）。
   - 非汉字里的符号（`✅✓✗❌⚠⛔❤⭐①②③④⑤▲▸▼▾●★` `←→↔⇒` `─│` `、。「」『』【】` `U+FE0F` 等）
     **已全部显式并入保留集**，且脚本复核差集 = **0**。
3. **生僻字自动落系统字体** —— 用户已接受。若界面出现 GB2312 外的生僻字，
   GDI+ 会按字体回退链（`Microsoft YaHei UI` 等）渲染，**不会显示成方框**；
   代价是**字宽可能跳变**（该字由系统字体出图，度量与 HarmonyOS 不同）。
4. **英文版 Windows 不受影响** —— 拉丁字母、数字、ASCII 标点全在保留集内；
   `UiVisualStyle.cs:97` 的回退族 `Microsoft YaHei UI` 在英文版 Windows 上同样存在。

## 为什么放在 `installer-src\字体子集\` 而不是 `installer-src\files\fonts\`

已核对 `installer-src\install_script.iss` 的 `[Files]` 段（第 31–32 行）：

```
Source: "files\Fonts\HarmonyOS_Sans_SC_Regular.ttf"; DestDir: "{app}\Fonts"; Flags: ignoreversion
Source: "files\Fonts\HarmonyOS_Sans_SC_Bold.ttf";    DestDir: "{app}\Fonts"; Flags: ignoreversion
```

**该段全部是逐条显式文件名，没有任何 `*` 通配符**（已全文核对 52 条 `Source:` 行）。
因此即使把 `SUBSET-KEEP.txt` 放进 `files\fonts\` 也**不会**被打包。

但本目录**仍然放在 `files\` 之外**，理由：

- **不赌未来**：以后若有人把 `[Files]` 改成 `files\Fonts\*` 或加 `Flags: recursesubdirs`，
  本目录不会被动进包 —— 属于"预防性隔离"，零成本。
- **`files\` 是发布载荷目录**（`files\` 下每个文件都对应一条 `Source:`），
  往里塞非载荷文件会**破坏该目录"所见即所发"的语义**。
