# 宝龙达抓包工具 —— 给机主的一页说明

**适用机型**：机械革命 **蛟龙16Pro（2022 / 2023 / 2024 年款）**，以及其它**宝龙达（Baolongda）模具**的机械革命机型

---

## 这是什么

一份**独立**的采集工具 —— 用来帮我们把 L-Mechrevo 支持到宝龙达模具的机器上。

⭐ **不需要装 L-Mechrevo**，⭐ **不需要联网**，⭐ **不需要任何专业知识**（就照下面点几下）。

---

## 三步走

```
⭐ 第一步 ⭐ 打开《要抓什么.txt》，按里面第 1 节运行 `运行抓包.ps1`
          （跑不起来就看《怎么运行.txt》）

⭐ 第二步 ⭐ 按《要抓什么.txt》第 2、3 节：
          用**官方控制台**把性能档 / 风扇 / 灯效各切一遍（每档停 3 秒），
          再把厂商日志文件夹复制进来

⭐ 第三步 ⭐ 按《要抓什么.txt》第 5 节**填那张小表**，
          然后把整个文件夹压缩发回
```

## ⛔ 安全承诺

```
⛔ 不写任何硬件寄存器      ⛔ 不写注册表        ⛔ 不改任何设置
⛔ 不装任何驱动            ⛔ 不联网上传        ⛔ 不读你的文档/聊天/浏览记录

✅ 只做三件事：① 读取硬件与系统信息  ② 生成一个新文件夹  ③ 打包成 zip
```

⭐ **你可以自己检查**：用记事本打开 `运行抓包.ps1`，里面全是 `Get-*`（读取）操作 ✅
⭐ 唯一写盘的地方是**新建的那个采集文件夹** ✅

## 我们会拿这些做什么（透明）

```
⭐ `02-ACPI-WMI接口.txt`  ⭐ **最关键** —— 找宝龙达那套接口的类名与 GUID，我们才能写探测代码
⭐ 厂商日志               看原厂控制台**调用顺序与参数**（我们要发一样的值）
⭐ 档位切换后的状态       对上"静音/均衡/狂暴"各对应什么值
⭐ 反馈小表               决定**先做哪些功能**（按你最想要的排）
```

## 常见问题（完整版见《要抓什么.txt》第 8 节）

**Q：会改我的机器吗？**  ⛔ 不会，全程只读。
**Q：一定要装官方控制台吗？**  ⭐ 强烈建议 —— 有它能看到"原厂怎么控"，没它我们只能猜，进度慢很多。
**Q：我不是蛟龙16Pro，是别的宝龙达机型？**  ✅ 一样有用，请在表里写清型号。
**Q：脚本报错/抓不全？**  ⭐ 能抓多少算多少，把 zip 发来 + 说下报了什么错即可。
