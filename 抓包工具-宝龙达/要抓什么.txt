# 要抓什么 —— 宝龙达机型（蛟龙16Pro 2022 / 2023 / 2024）

> 这份文件是给**机主**看的。目标机型：**机械革命 蛟龙16Pro（2022 / 2023 / 2024 年款）**，
> 也就是**宝龙达（Baolongda）模具**那一支。
>
> ⭐ 我们需要这些材料，才能把 L-Mechrevo 支持到你这台机器上。
> ⛔ **抓包过程不会改你机器上任何东西**（只读取、只生成一个新文件夹）。

---

## 0. 一句话总结：要做 4 件事

| | 做什么 | 大概耗时 |
|---|---|---|
| ① | ⭐ 运行 `运行抓包.ps1`（自动采集） | 1–2 分钟 |
| ② | ⭐ 用**厂商控制台**切一遍档位（我们要看它怎么发的） | 3 分钟 |
| ③ | ⭐ 把厂商控制台的**日志/配置文件夹**复制一份 | 2 分钟 |
| ④ | ⭐ 填一张**小表**（下面第 5 节） | 3 分钟 |

做完把产出的 **zip** 发回来就行 ✅

## 1. 运行抓包脚本（自动部分）

1. 把整个 `抓包工具-宝龙达` 文件夹放到桌面（⭐ 别放在 C 盘系统目录里）
2. **右键** `运行抓包.ps1` → **「使用 PowerShell 运行」**
3. 如果被系统拦住，看同目录的 **《怎么运行.txt》**（有一行命令可以解决）
4. 跑完后，同目录会多出一个 ⭐ **`宝龙达抓包-<日期时间>.zip`** ← ⭐ **这就是要发回的东西**

**脚本会自动采集**（你什么都不用做）：

```
01-机器信息.txt        ← ⭐ 机型、模具、BIOS、平台码、厂商注册表键
02-ACPI-WMI接口.txt    ← ⭐⭐ 最重要：root\WMI 下所有类 + 可疑接口的 GUID/方法/属性
03-厂商控制台.txt      ← 装了哪个控制台、文件版本、进程命令行
04-性能与风扇现状.txt   ← 电池/电源/风扇/温度/刷新率的当前状态
05-日志位置清单.txt     ← 厂商日志在哪（只列位置，方便你按第 3 节复制）
06-采集环境.txt        ← 环境信息，便于我们复现
```

## 2. ⭐ 用厂商控制台切一遍档位（脚本抓不到，必须手动）

> 目的：**看厂商控制台到底通过什么接口、发了什么值**。
> 我们要做的是"同一条路"，所以得先看清原厂怎么走。

⚠️ **前提**：先装好 ⭐ **官方控制台**（机械革命官网那套，装哪个版本都行），并**确认它能正常控制**你这台机器。

按顺序做，**每一步停 3 秒**（好让日志/状态落下来）：

```
□ 1. 打开官方控制台，进「性能模式」那一页
□ 2. 依次点：静音 → 均衡 → 狂暴（每档停 3 秒）
□ 3. 如果它有「自定义」档：进去看一眼（⛔ 不用改数值），能改就改一项、点应用、再改回来
□ 4. 进「风扇」页：把风扇转速从最低调到最高，再调回最低（每档停 3 秒）
□ 5. 进「灯效」页：
     □ 让键盘灯亮起来（单色 → 呼吸 → 彩虹，每档停 3 秒）
     □ 如果有灯带 / Logo 灯，也各切一遍
□ 6. 进「电池」页：如果有「充电限制 / 电池保护」，开关一次（⚠️ 别设成 0%，设成 60~80% 就行）
□ 7. 如果有「一键散热 / 强冷」，开一下再关
□ 8. 合上盖子前，⭐ 把控制台窗口**截图**（能看到版本号那一页最好）
```

⭐ **做完这一步之后**，再**重新运行一次 `运行抓包.ps1`**（⭐ 这样第 4、5 节能反映切换后的状态 ✅）

## 3. 把厂商控制台的日志/配置复制一份

打开脚本生成的 ⭐ `05-日志位置清单.txt`，里面列出了你机器上**实际存在**的路径。

⭐ **把这些文件夹整个复制**到抓包文件夹里（新建一个 `厂商日志` 子文件夹放进去）：

```
常见位置（清单里有的就复制，没有的跳过）：
  C:\ProgramData\Mechrevo\
  C:\ProgramData\ControlCenter\
  C:\ProgramData\MyControlCenter\
  C:\ProgramData\UniwillService\
  C:\ProgramData\AiStoneService\
  %LOCALAPPDATA%\Mechrevo\      （= C:\Users\你的用户名\AppData\Local\Mechrevo）
  %APPDATA%\Mechrevo\           （= C:\Users\你的用户名\AppData\Roaming\Mechrevo）
```

⚠️ **如果文件夹很大**（超过 200 MB）：`日志`、`log`、`logs` 这类子目录优先复制；
其余可以跳过（⭐ 告诉我们你跳过了哪些就行）。

## 4. ⭐ 如果方便的话，额外两样（很有用，但不强求）

```
□ A. 厂商控制台的**安装目录**清单（⭐ 不用复制文件，只要"目录树 + 文件名 + 版本号"）
     最省事的做法：在控制台安装目录里打开 PowerShell，运行：
        Get-ChildItem -Recurse -File | Select-Object FullName, Length, @{n='Ver';e={$_.VersionInfo.FileVersion}} | Export-Csv 安装目录清单.csv -Encoding UTF8
     ⭐ 把生成的 csv 放进抓包文件夹 ✅

□ B. 如果这台机器上**同时装得进另一个版本**的官方控制台（例如 5.17 与 5.56 都行），
     两版各做一次第 2 节 ⇒ ⭐ 我们能对比出接口有没有变 ✅
     ⚠️ 装不上 / 只能装一个版本 ⇒ ⭐ 跳过，不影响 ✅
```

## 8. 常见问题

**Q：跑脚本会改我的机器吗？**
A：⛔ 不会。脚本只做 `Get-*`（读取）并写一个新文件夹。你可以用记事本打开 `运行抓包.ps1` 自己检查。

**Q：一定要装官方控制台吗？**
A：⭐ 强烈建议。⭐ 有它我们能看到"原厂怎么控这台机器"；没有的话我们只能盲猜，进度会慢很多。

**Q：我的机器不是蛟龙16Pro，是别的宝龙达机型，能发吗？**
A：✅ 能，一样有用（⭐ 请在表里写清型号）。宝龙达模具的机型越全，适配越稳。

**Q：脚本报错/抓不全怎么办？**
A：⭐ 能抓多少算多少，⭐ 直接把 zip 发过来 + 说一下报了什么错 ✅。

**Q：里面有我的隐私吗？**
A：脚本采的是**硬件型号、驱动、接口、日志位置**这类信息（⭐ 不含文档/聊天/浏览记录 ✅）。
⚠️ 厂商日志可能含用户名与路径 —— 你可以在发之前自己打开看一遍。
