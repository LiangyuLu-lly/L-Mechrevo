# 怎么运行（PowerShell 脚本被拦住时看这里）

Windows 默认**不允许直接运行下载来的 .ps1 脚本**，这是微软的安全策略，不是你机器有问题 ✅

按下面**任一种**方法都能跑起来。

---

## 方法一：右键运行（最简单，先试这个）

1. 在 `运行抓包.ps1` 上 **右键**
2. 选 **「使用 PowerShell 运行」**
3. 如果弹出「Windows 已保护你的电脑」→ 点 **「仍要运行」**
4. 如果窗口一闪就没了 → 用方法二

---

## 方法二：⭐ 用一行命令绕过限制（推荐，最稳）

1. 在 `抓包工具-宝龙达` 文件夹里，**按住 Shift + 右键空白处** → 选 **「在此处打开 PowerShell 窗口」**
   （Win11 可能显示为「在终端中打开」）
2. 粘贴下面这行，回车：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\运行抓包.ps1"
```

⭐ **这行命令的意思是**：这次运行**临时**放开脚本限制，⛔ **不改系统设置、不改注册表** ✅

---

## 方法三：管理员身份运行（如果方法二报"权限不足"）

脚本**不需要管理员权限**也能跑（⭐ 只是少数项读不到 ✅）。
但如果你想让采集更全：

1. 开始菜单搜 **PowerShell** → **右键** → **「以管理员身份运行」**
2. `cd` 到本文件夹，例如：

```powershell
cd "$env:USERPROFILE\Desktop\抓包工具-宝龙达"
powershell -NoProfile -ExecutionPolicy Bypass -File ".\运行抓包.ps1"
```

---

## 方法四：实在跑不起来 → 手动版

⛔ **不要为了抓包去改系统策略**。跑不起来就直接告诉我们，
⭐ 我们会给你一份**可以手动执行的一小段命令**（复制粘贴到 PowerShell 里逐条跑）✅

---

## ⛔ 不要做的事

```
⛔ 不要执行 Set-ExecutionPolicy Unrestricted —— 那会永久放开你整台机器的脚本限制，没必要 ⚠️
⛔ 不要关杀毒软件 —— 脚本不需要
⛔ 不要为了抓包装任何驱动/工具 —— 脚本只用 Windows 自带的能力
```

⭐ 我们给的命令都是 `-ExecutionPolicy Bypass`（**只是这一次**），跑完自动恢复原样 ✅
