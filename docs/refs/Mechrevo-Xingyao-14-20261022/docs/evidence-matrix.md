# Evidence matrix

This matrix is the claim-level index for the documented MECHREVO Xingyao 14 / `P916F-STX`. It retains every row from the 118-line baseline matrix under stable `BASE-*` IDs and adds source-backed battery, thermal, firmware-access, setup, SREP, package, device and audio claims. `Evidence class` and `Source coverage` are separate: a historical live finding can remain live-confirmed when only its report is retained, while a complete-looking source excerpt does not become a live test.

Canonical class definitions and coverage terms are maintained in [`reverse-engineering-methodology.md`](reverse-engineering-methodology.md#evidence-classification). Source IDs `S1`–`S19` and exact locators are defined in [`research-sources.md`](research-sources.md#project-sources). Source links lead to public technical pages; File IDs identify provenance, not publicly downloadable evidence.

## Matrix maintenance rules

- A setter remains `Not tested` unless an invocation, initial state, response/readback and observed effect are retained. A getter does not promote its corresponding setter.
- `Rejected` is scoped to the stated machine, image and test; `Not established` is used where evidence is insufficient; `Not tested` is used where an operation was intentionally not performed.
- Behavioral semantics and exact lower-level mechanism are separate claims. A live behavior can be established while charger silicon, register naming or electrical implementation remains inferred or unestablished.
- Source coverage is not a confidence score. Full text can be inert candidate material, while a retained report can document a genuine historical live result.
- A located private source object is not represented as rehashed unless its raw bytes were actually exported and measured in the current audit.
- Source links point to the technical detail and the stable source-register ID. A missing source export belongs in [`documentation-status.md`](documentation-status.md#pending-evidence), not as a fabricated row or an unqualified fact.
