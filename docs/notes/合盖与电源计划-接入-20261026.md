## 2. WPF 新服务：`Services/LidSwitchService.cs`

中性服务，**不依赖任何窗口**：

1. 用 `HwndSource` 建 **message-only 窗口**（`ParentWindow = HWND_MESSAGE (-3)`，0×0）；
2. `NativeMethods.RegisterPowerSettingNotification(hwnd, PowerSettingGuid.LIDSWITCH_STATE_CHANGE, DEVICE_NOTIFY_WINDOW_HANDLE)`；
3. 钩 `WM_POWERBROADCAST (0x0218)` + `PBT_POWERSETTINGCHANGE (0x8013)`；
4. `Marshal.PtrToStructure<NativeMethods.POWERBROADCAST_SETTING>(lParam)` →
   `PowerSetting == GUID && DataLength ≥ 4` 才认；`Data 0 = 合盖 / 1 = 开盖`（与旧 `SettingsForm` 一致，
   长度校验沿用旧版 ConsoleDisplayState 的“防误读其它 GUID/短包”修正）；
5. 同状态重复通知**去重**（旧实现没去重；这里更保守，避免重复下发）；
6. 广播 `LidStateChanged(Closed)`；`LidClosed`/`Registered`/`LastError` 只读暴露；
7. `Start()` 失败只记 `[lid] …` 日志并返回 false（**安全 no-op**）；`Dispose()` 注销通知 + 移除钩子 + 销毁窗口；
8. `RunSelfCheck(out detail)`：校验 GUID 与常量，并用**合成 lParam** 验证 0/1 解析与 `DataLength<4` 拒绝
   —— ⛔ 不真实合盖、⛔ 不碰硬件，供启动日志/离线自检。

## 3. 键盘背光：HID / EC 分支的现有等价 API（OriginalStyleWindow 接线）

- 后端未连接 / HID 实例不可用 ⇒ 安全跳过并记录，⛔ 不假装成功；

## 7. 风险 / 未确认点

1. **真机真实合盖未验证**：只验证注册成功与解析逻辑；合盖实际关灯/开盖恢复需在真机上合一次盖确认（本任务明确禁止）。

   启动即合盖不会触发关灯（与旧 WinForms 注册方式相同；未额外发明初始探测，避免误判）。
3. 注册失败（无电源管理服务/被策略禁用）⇒ 安全 no-op；启动日志会如实打印 `未注册（安全 no-op，不伪造）`。

5. 合盖时未改 `LightingSettingsStore` / `rgb.cfg`（不写用户意图、不改配置），开盖按当前配置重放。
