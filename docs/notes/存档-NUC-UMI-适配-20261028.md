### 2. 性能模式

- NUC/UMI 首选 LM 直接下发 `OPERATING_*_MODE`
- 清理被配置编辑器污染的 30 系内置档固件槽
- 配置编辑器保存 fwXpY 时不再写内置 turbo/balanced/silent
- 高性能电源按性能模式按钮点击应用 Windows 电源模式
- 自定义档的 `WindowsPowerMode` 优先于高性能电源总开关默认映射
- LAPKC 首次路由前也能识别为 Intel NUC

### 3. 灯光

- 自动关灯小于 1 分钟只走软件计时，不再折算成 GCU 1 分钟
- 亚分钟计时使用 1s tick
- 已在诊断中看到灯带 Rainbow 下发，但实际效果仍无效
- 单色灯带颜色与展示仍存在误差
- NUC 灯带效果列表限制为单色/彩虹

### 4. 快捷开关

- 恢复 USB 供电、来电自启显示
- USB/来电自启无状态回包时按已下发成功处理
- APU 防缩缸恢复为 Windows 电源计划开关
- 小键盘锁在 NUC/UMI 改走本地模拟按键
- 高性能电源/APU 防缩缸状态从 PerfModeService 读取

### 5. 显卡/显示

- GPU 切换确认框居中屏幕
- 对话框打开期间 GPU 按钮不回弹
- 确认后立即显示黄色待重启态
- 多彩色彩增强切换后立即应用，不再需要手动开关一次
