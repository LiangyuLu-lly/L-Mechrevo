4. **`HID_EVENT20` 事件订阅**：原厂用 **WMI 事件**（不是 HID）做状态推送，可**替代 3 秒轮询**，
   还能拿到 Fn 热键/触摸板/飞行模式/性能档。⚠️ 本机没有这个类，**必须蛟龙真机验**。
   建议搭下一版的车做一个只读探测。
5. **`ControlCenter\{app}\` 那 266 MB 解开的目录**：原始安装包都留着、随时能重解，**建议删**。
6. **现场录像与截图（约 55 MB）**：在 `_upstream\captures\`，**建议留**（现场画面有时能补日志看不到的）。

## 六、六条贯穿性教训（这轮反复出现，值得放显眼处）

1. **`0xFF` 有四种含义** —— 未映射填充值 / 地址不存在 / **未进入 SuperIO 配置态** / 真的就是 0xFF。
   **单看数值不能作判据。**
2. **"调用没报错" ≠ 结果对** —— IOCTL 成功 ≠ 地址可达；回读变了 ≠ 灯变了；"读到了" ≠ "读对了"（可能是残留字节）。
3. **行尾陷阱**（本会话踩三次）—— `Strings*.resx` 混合行尾别用 `edit` 工具；`WriteAllLines` 会把纯 LF 转 CRLF；
   PowerShell `>` 重定向同样。**改前看 HEAD、改后回验。**
4. **假通过** —— "日志里没有错误"不等于"检查通过"（那五个关键字只在 `--ui-audit` 里输出，而它从未跑完）。
5. **电源壳工具陷阱** —— PowerShell `-shl` 对 `[byte]` 会**截断**（`[byte]0x81 -shl 8` = 0）⇒ 用 `* 256`。
6. **同名不同义** —— 两个项目都叫"EC 版本"却在不同地址；`0x2E`/`0x4E` 是同一套协议的两个槽位而非两套；
   芯片手册（IT5570）讲的是**芯片能力**，不是**厂商固件语义**。
