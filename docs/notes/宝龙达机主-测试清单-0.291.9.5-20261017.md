## 〇、测试前必须做的两件事

### 1. 重新安装（不是只换 dll）

本次包**新增了 7 个驱动文件**（`usbmidd_v2`，虚拟显示器驱动）——它是**安装期铺文件的**，
**光替换 dll 不生效**，必须**完整重装**这个包。

装完打开 LM，确认版本显示 `0.291.9.5 beta22.9.5`。

### 2. 跑一份诊断包

装好、重启一次电脑、正常用 5 分钟后，跑：
**设置 → 关于/诊断 → 生成诊断包**（或主界面入口），把 zip 发回来。

> 诊断包里 `②d` / `②e` / `②f` 三节是本次新增的 EC 通道探测，专门用来查下面第 8 项。

## 二、⭐ 键盘灯（你反馈过的那条）

### 现象（之前）

「键盘灯开了无法关闭」「亮度不能调节」

### 本次做了什么

- **关灯改成「写亮度 = 0」**（不再写"模式 0"——原厂也从不用模式 0 关灯）
- 修了一个真 bug：**界面第 1 档曾被算成硬件 0 = 灭灯**（所以你在最低档看到的是"灯灭了"而不是"变暗"）
- 修了两处"假成功"判定
- 灯效恢复**四项**：关 / 单色 / 自动循环 / 自定义颜色

### 请这样测

打开 **设置 → 灯光区 → 键盘灯**，效果下拉现在应有**四项**。依次做：

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| ① | 选「单色」＋改个颜色 | 颜色**应该跟着变**（这项你之前确认过可以用） |
| ② | 亮度滑块从最小拉到最大 | **应该有明暗变化**（以前第一档会直接灭灯，现在第一档是最暗而不是灭） |
| ③ | 亮度拉到 **0**（或直接选「关」） | **灯应该灭** |
| ④ | 选「**自动循环**」 | 灯应该自己变色/循环 —— ⭐ **原厂实际使用这个模式，理论上最可能生效** |
| ⑤ | 选「**自定义颜色**」 | ⚠️ **原厂定义了但从不使用**，最可能没反应 |

### 反馈什么

- ④/⑤ 若"选了没反应" ⇒ **直接说**，我会按能力位把那一项撤掉（不留"能点没反应"）

  ⇒ 那要换一条路（走 EC），请一定告诉我

## 八、⭐ EC 通道探测（诊断包里看，不用手动测）

诊断包里有三节新内容，**这是本次调查的重点**：

| 节 | 查什么 | 请回什么 |
|---|---|---|
| `②d` | ACPI EC 端口 `0x62`/`0x66` 读 XRAM | 该节全文 |
| `②e` | ACPI 标准空间 `0x80` 只读 | 该节全文 |
| `②f` | SuperIO 双槽位（`0x2E` vs `0x4E`）对照 | ⭐ **该节全文（最重要）** |

⭐ **特别看 `②f` 里 `0x2000` 这个地址**：
- 若能读到 **`0x55`** ⇒ 证明 SuperIO 通道**可用**，只是槽位因模具而异（这是好消息）
- 若两个槽位都是 `0xFF` ⇒ 说明这条路在你机器上走不通
