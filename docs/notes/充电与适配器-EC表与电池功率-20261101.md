# 充电、适配器与电池功率

日期：2026-11-01  
适用范围：同方 GCU（星耀、无界、GCU 机型）、NUC/UMI；宝龙达不显示充电功率。

## 1. EC 供电类型：0x7CC

```text
地址：0x7CC = 1996
用途：判断当前是圆口、Type-C，还是两者同时存在
```

掩码：

```text
bit0    = 圆口适配器
bit1~2  = Type-C 充电
```

| 0x7CC | 含义 |
|---|---|
| 0x00 | 未知 |
| 0x01 | 圆口 |
| 0x02 / 0x04 / 0x06 | Type-C |
| 0x03 / 0x05 / 0x07 | 圆口 + Type-C |
| 其它值 | 只取 bit0、bit1~2，其它位忽略 |

## 2. EC 适配器瓦数：0x49F

```text
地址：0x49F = 1183
用途：适配器额定功率编码
```

解码：

```text
code = raw & 0x78
```

| code | 额定功率 |
|---|---|
| 0x00 | 330W |
| 0x08 | 230W（界面显示 230/240W） |
| 0x10 | 180W |
| 0x18 | 150W |
| 0x20 | 120W |
| 0x28 | 90W |
| 0x30 | 65W |
| 0x38 | 40W |
| 0x40 | 280W |
| 0x48 | 210W |
| 0x50 | 250W |
| 0x58 | 420W |
| 其它 | 未知 |

代码：

```text
source/MechrevoLite.Hardware/PowerInputDecoder.cs
  TryDecodeAdapterWatts()
  DisplayAdapterWatts()
```

## 3. 适配器额定功率 ≠ 实际充电功率

```text
0x49F：插的是多大适配器（230W / 330W / ...）
BatteryRateWatts：当前实际充进电池多少 W
```

两者不能互相替代。

## 4. 电池充电功率

```text
source/MechrevoLite.Battery/BatteryRateReader.cs
```

读取方式：

```text
IOCTL_BATTERY_QUERY_TAG
IOCTL_BATTERY_QUERY_STATUS
→ BATTERY_STATUS.Rate（毫瓦）
→ / 1000 = W
```

特性：

```text
- 只读，不写 EC / 不写 ACPI
- 单次读取超时 1 秒
- Rate 为 int.MinValue 或驱动不返回 ⇒ null
- 电池充满、无电池、驱动不支持时可能没有值
```

采样：

```text
source/MechrevoLite/HardwareControl.cs
  RefreshBatteryRate()
  → HardwareControl.batteryRate
  → 每 5 秒刷新一次
```

WPF 服务：

```text
tools/dev/wpf-p0/Services/PowerStatusService.cs
  PowerStatusSnapshot.BatteryRateWatts
```

## 5. UI 显示

### 宽屏电池信息行

```text
tools/dev/wpf-p0/OriginalStyleWindow.xaml.cs
```

### 悬浮窗电池行

```text
tools/dev/wpf-p0/OverlayWindow.xaml.cs
  OverlaySnapshot.BatteryRateWatts
```

显示条件：

```text
非宝龙达
且 正在充电
且 BatteryRateWatts > 0
```

格式：

```text
电池 100% · 圆口 230/240W · 充电 45W · 已充满 · 循环 11 次
```

说明：

```text
- 圆口/Type-C 的适配器额定功率保留
- 充电功率只在真正充电时显示
- 已充满、未充电、放电、读不到 BatteryRateWatts ⇒ 不显示充电功率
- 宝龙达保持原样
```

## 6. 无界核显显存：25.5.1 口径

25.5.1：

```text
source/MechrevoLite/HardwareControl.cs
  num6 = lhmMonitor.GpuMemoryUsedMb
  num7 = lhmMonitor.GpuMemoryTotalMb
```

```text
source/MechrevoLite.Overlay/HardwareOverlay.cs
  _vramUsedMb = HardwareControl.vramUsedMb
  _vramUsage = HardwareControl.vramUsage
```

也就是说：

```text
只认 LHM 的 GPU Memory Used / Total（或 Dedicated Memory Used / Total）
不使用 D3D Shared Memory
```

D3D Shared Memory 是系统内存映射给核显的共享区，不是核显专用显存。

当前修复：

```text
移除 NoDgpu 的 shared memory 覆盖
恢复 25.5.1 的 GpuMemoryUsedMb / GpuMemoryTotalMb 口径
```
