# Fn 键探测与热键方案（2026-10-25）

## 结论

- 现有 Ctrl+Alt 快捷键使用 `RegisterHotKey`，不需要键盘监听。
- Fn+字母暂不实现，先存档；不同机型 Fn 行为可能不同。
- 一旦实现，应单独新增 `FnHotkeyService`，不要改动现有 `HotkeyService`。

## 本机探测结果

测试工具：

```text
_probe/fnprobe/fnkey-probe.ps1
```

日志：

```text
_probe/fnprobe/fnkey-probe.log
```

本机 Raw Input 能识别 Fn：

```text
RAW  vk=0xFF make=0x78 flags=0x0002 msg=0x0100
```

Fn+A / Fn+C / Fn+V 的顺序为：

```text
Fn down → 字母 down → 字母 up → Fn up
```

说明本机 Fn 在 Raw Input 的厂商键值中可见，理论上可实现 Fn+字母快捷键。

## 为什么暂不做

- Fn 的键值/可见性依赖键盘固件和机型。
- 不同机器可能完全没有 Raw Input 事件，或使用不同 usage/make code。
- 需要按机型验证，不能作为通用功能直接发布。
- 低级键盘钩子在本机没有收到 Fn；只有 Raw Input 收到。

## 将来实现时的接入点

- 使用 Raw Input：
  - `RIDEV_INPUTSINK`
  - 监听 `WM_INPUT`
  - `vk=0xFF + make=0x78` 作为 Fn
- 维护 Fn 按下状态，Fn 按住期间收到的字母作为组合。
- 配置写入 AppConfig，默认关闭。
- 不记录普通按键流，只处理 Fn 组合。
- 与现有 `HotkeyService` 并存，互不影响。
