## 八、当前结论（50 系 GCU）

1. **50 系 GCU = 1.2.0.0**，反编译在第一节；30/40 系 = 1.0.2.70，暂无完整反编译；
2. 三套 payload 的 `UserPofiles` 布局不同：30 系在 `UniwillService\`，40/50 在 `AiStoneService\`；
3. 50 系静音/性能档位：`Fan/Control` 的 `OPERATING_*` 动作 + 静音狂暴子模式（`SET_CPU_CORE_OFFSET_SILENT/EXTREME`），实现见 `MyControlCenter\MyFan\*` 系列；
4. LM 侧现在只依赖“命令 + 回读确认”，不依赖 GCU 的档位文件（30/40/50 均已在 LM 本地存档 + 启动重放范围内）。
