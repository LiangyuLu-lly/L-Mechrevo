## 2. 迁移方式

### XAML
- 扫描 `tools/dev/wpf-p0/**/*.xaml`（排除 obj/bin/bin-alt）中的
  `Text` / `Content` / `Header` / `ToolTip` / `Title` / `Watermark` 属性；
- 值替换为 `{x:Static loc:WpfStrings.<Key>}`；
- 根节点自动补 `xmlns:loc="clr-namespace:L_Mechrevo.WpfP0.Resources"`；
- 不做迁移：`Tag`、`x:Name`、绑定表达式、纯 ASCII/数字/单位、样式/模板 key。

### C# 代码
- 扫描 UI 赋值：`Text` / `Content` / `Title` / `Header` / `ToolTip` / `StatusText` / `Watermark = "..."`；
- 扫描 `MessageBox.Show(...)` 第一个中文字符串、`ToastForm/ToastService.Show*` 中文字符串；
- 替换为 `WpfStrings.<Key>`，并自动补 `using L_Mechrevo.WpfP0.Resources;`；
- 跳过：注释/`Logger.`/`Debug.`/`AppConfig`/`Publish(`/`Mqtt`/Tag 逻辑、字符串拼接（含 `+` 的表达式不拆，避免格式串丢失）、协议/命令/Tag 值。

### 键命名
- 优先“控件 x:Name + 属性”（XAML）或“类名 + 属性/消息类型”（C#），如
  `SettingsWindow_Text`、`CustomModeWindow_Content`、`TrayIcon_Content`；
- 同文本全局复用同一 key（`"应用"`、`"取消"`、`"刷新"` 等）；
- 冲突时追加 `_2`/`_3`；⛔ 不使用纯序号键（编号仅作同名冲突后缀）。
- 现有 15 个灯光/水冷键（`LightingKeyboard` 等）保持不变。

### 翻译
- zh-CN 资源值 = 原中文文案（逐字保留）；
- 中性 `WpfStrings.resx` 优先使用主程序集 `Strings.zh-CN.resx` ↔ `Strings.resx` 的键值映射自动翻译；
- **未能自动匹配的 363 条中性值暂时保留中文**（见 §5 未完成项），英文需人工补齐。
