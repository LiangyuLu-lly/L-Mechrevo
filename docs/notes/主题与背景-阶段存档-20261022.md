## 2. 为什么背景透底做不下去（实测结论）

WinForms 每个控件都是独立 HWND，透明靠父窗口重绘模拟；滚动移动子窗口 → 逐层重绘 → 残影/闪烁。本会话已尝试并回退：

| 尝试 | 结果 |
|---|---|
| `Color.Transparent` 递归透底 | 静态可看，滚动残影/重影 |
| 容器自绘「切片 + 半透明底」 | 静态变成半透明黑色地图，滚动脏 |
| `WS_EX_COMPOSITED` | 与自绘叠加，不动都在闪 |
| 滚动快照平移（CopyFromScreen + Blit） | 每次滚轮重拍图，卡顿、交互复杂 |
| 关/开双缓冲、整窗 Refresh | 分别导致闪烁或卡顿 |

结论：在 WinForms 控件树上无法同时满足「透底 + 平滑 + 交互」，需换 UI 框架（见 `WPF-迁移评估-20261022.md`）。
