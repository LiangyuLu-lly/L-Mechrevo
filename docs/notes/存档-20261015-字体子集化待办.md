### 为什么是"甲方案"
- 实测：扫 `source\` **374 个 .cs**（剔注释）+ **4 个 .resx** ⇒ UI 字符 **1118** = 汉字 964 + 非汉字 154
- **964 个汉字【0 个】不在 GB2312 一二级**（唯一例外 `U+9FFF` 只是 `UiAuditRunner.cs:1058` 的码位区间上界常量，非界面文字）
- 甲方案 = **GB2312 一二级全集（6763）+ 拉丁 + 数字 + 标点 + 全角 + 希腊/西里尔 + 箭头/制表 + 那 154 个符号** ⇒ 覆盖 100%
- ⚠️ 生僻字会自动落系统字体（**用户已接受**：「生僻字接微软雅黑呗」「英文版 Windows 用户又不用中文慌啥」）
- ⚠️ **不能删 Bold**：两个字重注册成同一字族（Regular w400 / Bold w700），`FontStyle.Bold` 真命中 Bold 面；**41 处在用**，最关键 `RButton.cs:803`（每个激活按钮每次重绘）+ `UiVisualStyle.cs:995/1091`（主按钮 + 所有卡片标题）
- ⚠️ **"假粗体"不可行**：实测 GDI+ 合成的中文粗体几乎看不出差别 ⇒ 加粗强调会集体失效
