### 0.1 WMI 调用方式（三份实现**完全一致**）

```csharp
// 出处：JiaoLongControl\Server\Core\Services\MethodServices.cs
using var mo = new ManagementObject("root\\WMI", "MICommonInterface.InstanceName='ACPI\\PNP0C14\\MIFS_0'", null);

### 0.3 ⭐ 风扇转速的字节布局（功能号 13）

```csharp
// 出处：MethodServices.GetValue<Tuple<int,int>>
new Tuple<int,int>((data[5] << 8) + data[4],   // Item1
                   (data[7] << 8) + data[6]);  // Item2

// 出处：FanController.GetFanSpeed()
CPUFanSpeed = CPUGPUFanSpeed.Item2;   // ⭐ = data[6..7]
GPUFanSpeed = CPUGPUFanSpeed.Item1;   // ⭐ = data[4..5]
```

⇒ ⭐ **`OutData[4..5]` = GPU 风扇 · `OutData[6..7]` = CPU 风扇**（⭐ 小端 16 位 ✅）
⚠️ Bellator 那份写的是"[4..5]=大扇1 / [6..7]=大扇2 / [10..11]=小扇"（⭐ 联想机型有 3 个风扇 ✅）
⇒ ⭐ **蛟龙16Pro 是 2 个风扇**，⭐ 命名不同但**字节布局一致** ✅

### 0.4 ⭐ `CPUPower`（功能号 23）—— 自定义模式的**子命令**协议

```
⭐ 写单字节子命令（`SetValue` 直接传枚举值）：
   ⭐ **0 = CloseState**      关闭自定义
   ⭐ **1 = OpenState**       开启自定义
⭐ 写**两字节** `[子命令, 值]`（`SetValue(MethodName.CPUPower, new byte[]{子命令, 值})`）：
   ⭐ **2 = LongPower**       ⭐ **PL1（长时功耗）**
   ⭐ **3 = ShortPower**      ⭐ **PL2（短时功耗）**
   ⭐ **4 = CpuTempWallState** ⭐ **CPU 温度墙**
⭐ 读：`OutData[4]`，⭐ 1 = 自定义已开启 ✅
```

### 0.5 ⭐⭐ EC 直写协议（⭐ 蛟龙16Pro **自己的驱动**）

出处：`JiaoLongControl\Server\Core\Drivers\Blding64.cs`（⭐ 类名 `Blding64` = **BLD**ing = 宝龙达 ✅）

```
⭐ 驱动文件 : ⭐ **`JiaoLongDriver64.dll`** + ⭐ **`JiaoLongDriver64.sys`**（⭐ 随包分发，安装为服务同名）
⭐ 导出函数 : ⭐ `InitializeBldring()` / `ShutdownBldring()`
              ⭐ `GetBLDPortVal(ushort port, ref byte val, byte size)`
              ⭐ `SetBLDPortVal(ushort port, byte val, byte size)`
⭐ 端口     : ⭐ `EC_ADDR_PORT = 0x4E`（⭐ 写**命令**）· ⭐ `EC_DATA_PORT = 0x4F`（⭐ 写地址/数据）
⭐ 访问协议（⭐ 三段式，⭐ 很关键）：
   ⭐ ① 命令 `0x11` + ⭐ **地址高字节**   ⇒ 设置目标地址高位
   ⭐ ② 命令 `0x10` + ⭐ **地址低字节**   ⇒ 设置目标地址低位
   ⭐ ③ 命令 `0x12` + ⭐ **数据**（写）/ ⭐ 读端口（读）⇒ 完成一次 RAM 读写
   （⭐ 写法：`port 0x4E ← 命令`，然后 `port 0x4F ← 参数` ✅）
```

| 地址 | 名称 | 说明 |
|---|---|---|
| ⭐ **0xC834** | `Fan1_RPM` | 风扇1 实际转速 |
| ⭐ **0xC835** | `Fan2_RPM` | 风扇2 实际转速 |
| ⭐ **0xC836** | `Fan1_RPM_Level` | 风扇1 档位 |
| ⭐ **0xC837** | `Fan2_RPM_Level` | 风扇2 档位 |
| ⭐ **0xC83C** | `Fan1_RPM_SET` | ⭐ **风扇1 目标转速（写）** |
| ⭐ **0xC83D** | `Fan2_RPM_SET` | ⭐ **风扇2 目标转速（写）** |
| ⭐ **0xC411** | `EC_Version` | EC 版本 |
| ⭐ **0xB20** | （手动模式掩码） | ⭐ **bit1 = CPU 扇手动 · bit3 = GPU 扇手动** |
| 0x2000 | EC 芯片 ID | == **0x55** 时执行初始化 |
| 0x1060 | 初始化标志 | 置 **bit7** |

#### 0.5.2 ⭐ 风扇手动控制时序（⭐ 我们要照做的）

```
⭐ 初始化（构造时）：
   if (EC_RAM_READ(0x2000) == 0x55)  EC_RAM_WRITE(0x1060, EC_RAM_READ(0x1060) | 0x80)

⭐ CPU 扇手动：EC_RAM_WRITE(0xC83C, speed)
              EC_RAM_WRITE(0xB20, EC_RAM_READ(0xB20) | 0x02)
⭐ GPU 扇手动：EC_RAM_WRITE(0xC83D, speed)
              EC_RAM_WRITE(0xB20, EC_RAM_READ(0xB20) | 0x08)

⭐ 恢复固件控制（RemoveFanSpeed）：两扇都写 0 ⇒ 再把 0xB20 整体写 **0x00**

⭐⭐ 重要注意事项（⭐ 原作者踩过的坑）：
   ⭐ `FanController.SetFanSpeed` 里**先检查并关掉** `MaxFanSpeedSwitch`（功能号 20）
      —— 注释原话：「**此处为兼容性设置，为避免官方控制台冲突设计**」
   ⇒ ⭐ 我们接宝龙达时**必须照做**（⭐ 否则和官方控制台互相打架 ✅）
```

### 4.1 ⭐⭐ 性能模式编号的**精确对照**（⭐ 这是最大的风险点）

```
⭐ 我们的链路（两跳）：
   ⭐ `MechrevoHw.OperatingMode`（内部）
   ⭐ → `LegacyMifsWmi.BuildModeRequest` 映射 → ⭐ **MIFS 原始号**
   ⭐ 映射表（`LegacyMifsWmi.cs:77-83`）：内部 **0→MIFS 2** · 内部 **1→MIFS 0** · 内部 **2→MIFS 1**
   ⭐ 且 `MechrevoHw.GHelperMode`（`:1824`）：内部 0→**2(turbo)** · 1→**0(balanced)** · 2→**1(performance)** · 3→4(custom)

⭐ Baolongda / 蛟龙16Pro 的 MIFS 原始语义（⭐ `SysEnums.SystemPerMode`）：
   ⭐ **MIFS 0 = BalanceMode（平衡）** · ⭐ **MIFS 1 = PerformanceMode（增强）** · ⭐ **MIFS 2 = QuietMode（静音）**

⭐⭐ 逐项对照 ⇒ **两个对得上、一个对不上** ⚠️：
   ┌ MIFS 0 ── 我们当"内部 1(balanced)" · 宝龙达当"平衡"          ⇒ ⭐ **一致** ✅
   ├ MIFS 1 ── 我们当"内部 2(performance)" · 宝龙达当"增强"        ⇒ ⭐ **一致** ✅
   └ MIFS 2 ── 我们当"内部 0(**turbo/狂暴**)" ⚠️ · 宝龙达当"**静音**" ❌ ⭐ **语义相反！**
⭐⭐ ⇒ ⭐ **后果**：⭐ 若直接复用 `LegacyMifsWmi` 接宝龙达 ⇒
   ⭐ 用户在**蛟龙16Pro** 上点「静音」会**变成狂暴**、点「狂暴」会**变成静音** ❌❌
   ⭐ ⇒ ⭐⭐ **这是接宝龙达时【必须先处理】的一件事**（⭐ 不是"验证一下"而已 ✅）
⚠️ 但⛔ **不能直接改 `LegacyMifsWmi` 的映射表** —— 那会让**现有老同方机型**的档位反过来 ❌
   ⇒ ⭐ **正确做法**：⭐ 在**宝龙达后端**里自己做一层映射（⭐ 不动老接口的共用代码 ✅）
   ⭐ 或给 `LegacyMifsWmi` 加一个"平台语义"参数，⭐ 由后端决定用哪套 ✅
   ⇒ ⭐⚠️ **这一点必须真机确认**（⭐ 也可能老同方机型本来就是"2=静音"、
      是我们当年的口径就记反了）⭐ 所以：⭐ **先在宝龙达上量一次真机读数**，
      ⭐ 看"点静音时 MIFS 读回几" ⇒ ⭐ 以真机为准 ✅
