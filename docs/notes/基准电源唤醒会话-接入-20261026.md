## 1. 电源事件映射（旧 Program → WPF）

| 旧 WinForms `Program.cs` | WPF 位置（本次） | 行为 |
|---|---|---|
| `SystemEvents.PowerModeChanged`（`:3601`） | `OriginalStyleWindow.OnPowerModeChanged`（`:1378`） | `Suspend`：记录键盘灯状态；`Resume`：90s 抑制第二实例唤起 + 1.5s 后灯光/键盘灯恢复；所有模式变化后调度 2s 电源稳定检查 |
| `SchedulePowerCheck` → `OnPowerSettled`（`:3589`） | `SchedulePowerSettle` + `OnPowerSettledAsync`（`:1431/1451`） | 仅当电源线状态真的变化：`BatteryControl.AutoBattery()` → `PerfModeService.ReplayAsync(powerSourceChanged:true)` → `ReconcileLightingPowerAsync()` → `ScreenControl.AutoScreen()`（内部 `screen_auto` 关闭时 no-op） |
| `SetAutoModes(powerChanged:true)` 的自动模式 | `PerfModeService.ReplayAsync("电源变化", powerSourceChanged:true, appSideOnly:false)` | 使用 `PerfModeStore.ActiveFor(powerKey)` 的“按电源来源记住的档位”；Wujie 自定义档保持当前档（旧实现的同一门控） |
| `SetAutoModes` 的电源来源 | `_lastPowerLineOnline` + `PowerStatusService`/`SystemInformation.PowerStatus` | 只在 **online 状态变化**时动作，避免唤醒/窗口显示误触发 |

> 「不覆盖用户手动选择」：`ReplayAsync` 只在 `powerSourceChanged` 时按 store 的电源档位重放；未变化不切档；Wujie 自定义档不自动跳。`ScreenControl.AutoScreen()` 仅 `screen_auto` 打开时生效，旧基线同样是“仅真插拔/开机首次”。
