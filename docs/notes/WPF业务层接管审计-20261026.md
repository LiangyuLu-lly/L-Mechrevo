## 0. 结论摘要

1. **WPF 不是“把旧 WinForms 窗口嵌进来”，而是一次 UI 重写**：
   - `tools/dev/wpf-p0/OriginalStyleWindow.xaml.cs`（窄窗，5490 行）与 `MainWindow.xaml.cs`（宽窗，1941 行）重写了旧 `source/MechrevoLite/SettingsForm.cs`（约 1.99 万行）的绝大部分 UI 与事件流程。
   - 真正通过 `OriginalFormHostWindow` 托管的旧 WinForms 窗体**只有** `FirstRunGuideForm`（`OriginalStyleWindow.xaml.cs:2995`、`:3013`）；旧 `CustomModeForm` 字段 `_legacyCustomModeForm` 只声明未使用（`:65`）。
2. **WPF 复用旧程序集的方式是“服务/静态类型”复用，不是窗口复用**：
   - `BackendProbe` 自己 `new MechrevoHw()` / `ConnectAsync()` / `new MechrevoService(hw)`，再把实例写回旧 `Program.hw` / `Program.service`，因此旧程序集里所有 `Program.hw` / `Program.service` 调用点都能在 WPF 下工作。
   - 旧 UI 的**业务判断与协议实现**（`MechrevoHw`、`MechrevoService`、`PerfModeService`、`ModeControl`、`BatteryControl`、`DiagnosticPack*`、`UpdateChecker`、`AppConfig` 等）被 WPF 直接复用。
   - 旧 UI 的**事件编排/行构建逻辑**没有被 WPF 复用，WPF 自己重写了一份（这是当前最大的重复与回归面）。
3. **删除旧 UI 的主要阻塞不是“窗口还在被托管”，而是 WPF 对旧 WinForms 程序集的静态/工具类耦合**：
   - `Program.hw/service` 全局静态（约 30+ 处，见 §3）；
   - 旧 UI 窗体里的“数据表/判定函数”（`LightForm.*Effects`、`RgbForm.VisibleHidEffects`、`CustomModeForm.IsOffered/IsGen40Plus`、`HardwareControl` 传感器采样）；
   - 旧 `UpdateForm.TemporarilyHidden`、`CustomMenuRenderer` 等 UI 级工具；
   - `OriginalFormHostWindow` 对 `FirstRunGuideForm` 的托管。
4. 建议按 **P0 解除静态耦合 → P1 抽共享 UI 数据/判定 → P2 移除旧窗体与清理** 三步推进；P0 完成前不能删 `source/MechrevoLite` 的 WinForms 工程。

### 3.2 建议的共享服务边界
1. **`IBackendHost`/`BackendSession`（P0）**：把 `MechrevoHw` + `MechrevoService` + `Program.acpi` + `Program.hardwareOverlay` 的创建/生命周期/重连收进 WPF 共享单例；`BackendProbe` 只做 UI 适配；删除 `Program.hw/service` 的公开 setter（或至少在 WPF 下改为只读属性）。
2. **`ISensorSnapshot`（P1）**：把 `HardwareControl` 的静态字段（cpuPower/gpuPower/温度/风扇/电量）改为可注入的快照服务；WPF 悬浮窗/宽窗/反馈包统一读快照。
3. **`ILightingCatalog`（P1）**：把 `LightForm.*Effects`、`RgbForm.VisibleHidEffects`、`KeyboardFirmwareEffects` 抽到中性程序集（不依赖 WinForms），WPF 与保留的旧窗体共用。
4. **`IUpdateService` / `IDiagnosticPackService`（P1）**：`UpdateChecker`、`DiagnosticPack*` 已是服务类，只需去除对 `UpdateForm`/WinForms 对话框的静态引用。
5. **`FirstRunGuide` 迁移或保留宿主（P2）**：若保留 `FirstRunGuideForm`，`OriginalFormHostWindow` 必须保留对 WinForms 的引用 ⇒ 旧 UI 工程不能整包删除。
