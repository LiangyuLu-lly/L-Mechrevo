## 2. 做法

1. 用 XML 读取中性 `WpfStrings.resx`，筛出 `<value>` 含 `[\u4e00-\u9fff]` 的 key，导出 `work/untranslated.tsv`（261 条）。
2. 按 key/上下文逐条翻译，生成 `work/en-translations.tsv`（`key<TAB>English`），规则：
   - 保留 `{0}`/`%`/单位（W、MHz、s、℃ 等）、品牌名（L-Mechrevo、GCU、MiniLED、Paid）、协议键、版本号、URL；
   - 拼接片段保留首尾空格/冒号/引号语义（如 `"CPU probe failed: "`、`"Delete mode \""`）；
   - 长句按 key 名与调用点上下文给自然英文，不留中文。
3. 用 `XmlDocument.PreserveWhitespace=true` 逐 key 设置 `<value>.InnerText`，保存为 UTF-8（无 BOM）；只改 value，不改 key/顺序/结构。
4. 校验：
   - key 数 655 不变；
   - 剩余中文 value = 0；
   - 与 `zh-CN.resx` 逐 key 对比 `\{[^}]+\}` 占位符集合，不一致 = 0；
   - XML 读取通过，构建通过。
