# WPF 业务层迁移进度（2026-10-26 第 2 轮）

> 基线审计：`docs/notes/WPF业务层接管审计-20261026.md`（P0 6 / P1 6 / P2 5）。

## 已完成

### P0-1：独立后端生命周期宿主 ✅

- 新增 `Services/BackendHost.cs`：唯一负责 `BackendProbe` 创建、15s 连接超时、失败释放、重试、Dispose。
- `OriginalStyleWindow.ConnectBackendAsync` 不再 `new BackendProbe` / 直接 `Dispose`，改由 `BackendHost.ConnectAsync(...)`；窗口只持有结果。
- 关闭时只 `_backendHost.Dispose()`，不再重复释放探针。
- 连接成功仍由 `BackendHost` 调 `WpfBackend.Attach(...)` 发布。

### P0-2：后端静态桥统一 ✅

- 新增 `WpfBackend` 作为 WPF 唯一静态后端桥；旧程序集内部仍可读 `Program.hw/service`，桥接赋值时同步写回。
- 所有窗口/服务不再直接读写 `Program.hw/service`；`WpfBackend.Attach(...)` 为唯一挂载入口。
- 验收：递归 grep WPF `*.cs` 的 `Program.hw|Program.service` 仅命中 `WpfBackend.cs` 桥接实现。

### P0-6：更新开关去掉旧 UI 常量 ✅（诊断服务仍属业务程序集）

- `SettingsWindow`/`OriginalStyleWindow` 不再引用旧 `UpdateForm` 类型。

### P0-2：移除 WPF 对 Program.hw/service 的直接依赖 ✅

- 所有 WPF 窗口/服务改为 `WpfBackend.Hw/Service`；`WpfBackend` 在赋值时同步写回旧程序集需要的 `MechrevoLite.Program.hw/service`，保证旧业务程序集仍能工作。
