### 6. ⭐ 首次启动「5s 刷新」不够 —— 阶梯 + **重启级**（已完成并**真机验证**）
**机制查明**：不是「启动后 5s」，是「**确认连上 GCU 后 5s**」（`GcuWarmupReload.cs`）。
**根因**：原实现是**一次性闩**（`gcu_warmup_reload_done` 一写永不重来）⇒ 晚于 5s 上报的能力位**不重启永不回来**。

**第一步**：改成 **固定重试阶梯 `[5s, 15s, 30s, 60s]`**，判据齐了**提前收手**；
**三重幂等闩**：固定长度（无再入路径）+ 进程内 `Interlocked` 闩 + 跨进程 config 标记。
保留原有「仍判不支持 ⇒ **提示**重启」兜底（**是提示不是自动重启**）。⛔ 未选自动重启。

**第二步（用户原话「当前只是刷新界面 好像用处不大 应当是重新检查一次能力然后刷新的 应该和启动 LM 差不多」）**：
把"软重载"从 2 步升级为 **4 步 = 与启动路径对齐**：
1. ⭐ `await hw.RequestInitialStateAsync()` —— 主动发全套 `GETSTATUS` + `Customize/Control GETSUPPORT`
   + `BatteryProtection/Control GET`（**与 `ConnectAsync` 调用的是同一个方法**；老接口后端在其内部自己分支）
2. `await Task.Delay(RestartGradeWaitMs)`（新常量 **800ms**）—— 等 GCU 把新值写进快照
3. `ReloadCapabilities()`（重读 ItemSupport 快照）
4. `RefreshDeviceCapabilities()`（重算 UI）

`Run` 改为 `async void`（UI 线程，`await` 期间不阻塞界面）；失败/超时**只记日志不外抛**；
**全程有界**：一拍 = 一次批量查询 + 一次固定等待，**不轮询、不重试、不断线**
（断线重连仍归 `MqttReconnectCoordinator`，本类不碰）。另补 **`gcu-warmup-done-skip`** 日志
（原先"跳过阶梯"是**静默的**，诊断包里看不出原因）。

## 五、踩坑记录（给后续代理/自己）

1. ⚠️ **`AppConfig` 没有 `GetInt`** —— 只有 `Get(string name, int empty = -1)` / `Is(string)` / `Set(...)` /
   `GetString(...)`。某轮代理的补丁脚本写了 `AppConfig.GetInt(...)`，**即使执行也编译不过**。
2. ⚠️ **`Strings.cs` 是手工维护的**（带 `[GeneratedCode]` 但含中文 `/// <summary>`）⇒
   **任何新 resx 键都必须同步补 `Strings.cs` 静态属性**，否则编译期取用失败。改已有键的**值**则不用补。
3. ⚠️ **本树未开 nullable** ⇒ 新代码写 `?` 类型注解会引入 **CS8632**（基线 1447 会涨）。
   既有文件里已有的 `?` 保留即可，**新增代码避免**。
4. ⚠️ **路径里是点号不是子目录**：`source\MechrevoLite.Properties.Strings.resx`、
   `source\MechrevoLite.Properties\Strings.cs`（同名但一个在文件名里、一个是目录）。`-Filter 'Strings*'` **匹配不到**前者。
5. ⚠️ **代理会失败**：某轮代理因"执行策略拦截脚本"**中途失败**，留下了**半成品** `.new` 文件与临时补丁脚本
   （已清理）。接手时**先核对目标文件的 SHA/mtime**，别把半成品当成品。
6. ⭐ **死代码陷阱**：`tableScreen`/`panelScreen` 在 `SettingsForm.cs` 里看着像刷新率区的实现，
   其实**从未被加进任何容器** ⇒ 改它们**不生效**。真正在用的是 `_hzSegTable`。
7. ⚠️⭐ **`edit` 工具会把"混合行尾"的文件规范成纯 LF** —— 实测：两份 `Strings.resx` 原本是
   **14 CRLF + 其余 LF**（那 14 个 CRLF 只属于 `DgpuRiskDgpuDrivesDisplay` 与 `IgpuOnlyForceSecondConfirm`
   两个条目，是更早某轮代理留下的），用 `edit` 插入后变成 **CRLF=0**（纯 LF）。
   - ⚠️ 纯 LF 文件（`SettingsForm.cs`/`Strings.cs`/`GcuWarmupReload.cs`）与**纯 CRLF** 文件
