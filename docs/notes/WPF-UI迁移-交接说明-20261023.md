## 5. 后端接入方式

WPF 原型 **ProjectReference** 引用主工程：

```xml
<ProjectReference Include="..\..\..\source\L-Mechrevo.csproj" />
```

为了复用现有 internal 方法，主工程 `source/Properties/AssemblyInfo.cs` 增加了：

```csharp
[assembly: InternalsVisibleTo("L-Mechrevo.WpfP0")]
```

**原则：优先复用 LM 现有接口/现有类，不新写硬件接口。**

`BackendProbe.cs` 创建自己的：

- `MechrevoHw`
- `MechrevoService`

并负责：

- 1 秒刷新 CPU/GPU 温度、风扇、电池、模式；
- 快捷开关 `SwitchQuick` / `fanboost → SwitchFanBoost`；
- 性能模式视觉档映射：静音=2 / 平衡=0 / 狂暴=1 / 自定义=3；
- 显卡模式：
  - GCU：`CanSwitchGpuMode` + `SwitchGpuMode` / `RequestGpuModeRestartAsync` + `RefreshGpuModeStatus`
  - 宝龙达：`TrySetGpuModeViaBackend`（界面 1=混合 / 2=独显；0 拒绝）
- 电池：`SetBatteryProtection`、`BatteryControl.CaptureChargeLimitGesture` / `ApplyChargeLimitFromUserGesture`
- 官方控制台/PawnIO：`OfficialConsoleIsolation` / `PawnIOInstaller`
- 设置备份：`SettingsBackup`
- 开机自启：`Startup`

## 7. 当前未完成/待验证

1. **字体渲染策略（已定）**
   - 默认：首次启动把 `Assets/Fonts/HarmonyOS_Sans_SC_Regular/Bold.ttf` 注册到当前用户字体目录（`%LOCALAPPDATA%\Microsoft\Windows\Fonts` + HKCU 字体注册表 + `AddFontResource`），随后用系统字体族；
   - 已安装系统字体则直接使用，不重复安装；
   - 保底：安装失败时回退 `FontFamily(文件路径#HarmonyOS Sans SC)`；
   - 排版统一 `TextFormattingMode=Ideal` + `TextRenderingMode=ClearType`；
   - 本机对比结论：本地字体 + Ideal 明显优于 Display；系统字体与本地文件在 Ideal 下观感接近，安装只是保证字体链接完整。
   - 仍存在的差异：LM 原版按钮走 GDI `TextRenderer.DrawText`，WPF 走 DirectWrite，约 9% 像素差无法完全消除。
2. 灯光“编辑”按钮还未接编辑器；
3. 色彩增强下拉、屏幕校色下拉的完整状态回读还需按 LM 逻辑补；
4. 设置页部分控件布局仍需按 LM 原版继续细调；
5. P1 尚未合并进主程序，主程序仍是 WinForms；
6. 主程序安装包/源码包尚未因新改动重新打包（机主未要求打包）。
