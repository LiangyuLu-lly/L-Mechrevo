## 3. ⭐ 「同方装了这个包」会看到什么（⭐ 需求 ③）

```
⭐ 在 `PrepareToInstall`（⭐ 用户点「安装」那一刻、⭐ **任何文件落盘之前** ✅）判：
   ⭐ `if NoGcuPackage() and (not IsBaolongdaMold())` ⇒ ⭐ **弹框明确告知** ✅：
      ┌────────────────────────────────────────────────┐
      │ 本安装包【未包含 GCU 组件】，仅适用于宝龙达模具    │
      │ 机型（蛟龙16Pro 30/40 系）。                    │
      │                                                │
      │ 检测到本机主板型号为：XXXX                       │
      │ 该型号属同方模具 => 本包装不上 GCU，GCU 相关      │
      │ 功能将不可用。                                  │
      │                                                │
      │ 请改用正式版安装包（含 GCU）。                    │
      │                                                │
      │ 是否仍然继续安装（主程序可用，但 GCU 功能不可用）？ │
      └────────────────────────────────────────────────┘
      ⭐ 「是」⇒ ⭐ 继续装（⭐ 主程序可用 ✅、⭐ GCU 功能不可用 ⚠️）
      ⭐ 「否」⇒ ⭐ `Abort` ⇒ ⭐ Inno **干净地中止** ✅（⭐ 此刻零文件落盘 ⇒ ⭐ 零半装 ✅）
⚠️ ⭐ **提示里带上检测到的主板型号** ✅ —— ⭐ 便于用户判断、⭐ 也便于我们排查 ✅
⚠️ ⭐ **刻意不使用 `Result`** ⚠️：⭐ 本文件既有铁律「⭐ `Result` 一律保持 `''`，⭐ 任何情况都不中止安装 ✅」
   ⇒ ⭐ 取消走 ⭐ `Abort` ✅（⭐ 另一个机制 ✅，⭐ 不违反那条铁律 ✅）
⚠️ ⭐ **机型判据没有放宽** ✅ —— ⭐ 判据只在宝龙达那条路用 ✅
```

## 4. ⭐ 怎么构建两种包

```
⭐ **含 GCU（默认，⭐ 主包）**：
   & 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' 'D:\openLM\installer-src\install_script.iss'
   => Output\LM-0.291.9-beta22.9-test-setup.exe

⭐ **不含 GCU（宝龙达专用测试包）**：
   & 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' '/DNOGCU' 'D:\openLM\installer-src\install_script.iss'
   => Output\LM-0.291.9-beta22.9-baolongda-test-setup.exe
```
```
⚠️ 两种包**都要先**跑一遍：
   ⭐ `dotnet build source\L-Mechrevo.csproj -c Release`（⭐ 0 错误 ✅）
   ⭐ `dotnet publish ... -o rebuild\lm_fix_build -p:NoWarn=WFO1000%3BCA1416`
   ⭐ `py -3 tools\merge_and_clean.py --apply`
⚠️ ⭐ 两者**产物名不同** ⇒ ⭐ 互不覆盖 ✅、⭐ 也不覆盖 `LM-0.291.8.1-...` ✅
```

## 8. ⭐ 给后续人的三条提醒

```
⭐ ① ⚠️ **`.iss` 是 UTF-8 无 BOM ＋ CRLF** ✅ —— ⭐ 改完**必须保持** ✅
      （⭐ 带中文的 `.ps1`/`.txt` 则**必须有 BOM** ⚠️，⭐ 否则机主 PS 5.1 语法错 ❌）
⭐ ② ⚠️ **ASCII 引号坑**：⭐ 代码/脚本字符串里**⛔ 绝不用** `"` 包中文 ⇒ ⭐ 用「」✅
      ⚠️ ⭐ **"偶数校验"也不够** ⚠️（⭐ 把 `"x"` 塞进已双引号的串里 = ⭐ 4 个引号、⭐ 偶数 ⚠️）⇒ ⭐ 只能手工写对 ✅
⭐ ③ ⚠️ ⭐ **凡是给"dontcopy 载荷"加 `Check` 或 `#ifndef` 排除的**，
      ⭐ ⭐ **必须同步检查解压函数有没有提前退出** ⚠️
      ⇒ ⭐ 否则 ⭐ 载荷解不出 ⇒ ⭐ `Failed` 非空 ⇒ ⭐ `PrepareToInstall` Exit ⇒ ⭐ ⭐ **安装被中止** ❌
```
